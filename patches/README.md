# Chromium patches

No Chromium source patches are currently applied.

Start with a clean upstream build. Add one narrowly scoped patch at a time and record:
- exact Chromium commit SHA;
- rationale and affected subsystem;
- benchmark hypothesis and reproducible command;
- compatibility and security regression coverage;
- measured results and rollback instructions.

See chromium/PATCH_POLICY.md. Do not optimize before the upstream baseline exists.
