# Chromium upstream

Repository: https://chromium.googlesource.com/chromium/src.git

Before first build:
1. Select an appropriate stable Chromium revision.
2. Verify Android API 36 / Android 16 build compatibility.
3. Record full 40-character commit SHA, branch/channel, selection date and build-tool versions.
4. Build the unmodified `system_webview_apk` target.
5. Only then begin patching.

Do not use a moving branch name as reproducible build provenance.
